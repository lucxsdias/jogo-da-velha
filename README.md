# Jogo da Velha Narrativo

Jogo da velha para navegador desenvolvido como projeto de estudo.

A proposta é começar com as regras tradicionais e evoluir gradualmente para uma experiência narrativa de suspense, com uma adversária misteriosa, regras especiais, cartas e eventos.

## Estado atual

A primeira versão possui:

- tabuleiro 3×3;
- nove casas criadas com JavaScript;
- interface organizada com CSS Grid;
- interação de clique;
- marcação provisória com `X`;
- projeto executado e empacotado com Vite.

O jogo ainda não possui alternância de turnos, validação de jogadas ou condição de vitória.

## Tecnologias

- HTML;
- CSS;
- JavaScript;
- Vite;
- npm;
- Git e GitHub.
